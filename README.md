# Классификатор тональности отзывов на русском

Модель определяет тональность отзыва (негатив / нейтрально / позитив) и решает, можно ли отвечать на него автоматически или нужно отдать человеку.

Данные: [RuReviews](https://github.com/sismetanin/rureviews) — 90 тыс. отзывов на женскую одежду с крупного маркетплейса, по 30 тыс. на класс. Метки проставлены автоматически по звёздам, которые поставил покупатель.

## Запуск

```bash
pip install -r requirements.txt
python scripts/download_data.py
python -m src.data       # чистка, дедупликация, разбиение 80/10/10
```
